# Сайт нотаріусів Анцут

## Структура

- `index.html` — структура сторінки та її вміст.
- `styles.css` — оформлення, адаптивна верстка й анімації.
- `script.js` — меню, FAQ, модальне вікно та взаємодія з API.
- `server.py` — локальний Python-сервер і бекенд для перевірки форми.
- `contracts.html`, `inheritance.html`, `powers-of-attorney.html`, `certifications.html`, `real-estate.html`, `other-services.html` — окремі сторінки напрямів послуг.
- `prices.html` — орієнтовні діапазони з датованого прайсу нотаріуса в Києві, застереження щодо їх застосування та що уточнити до візиту.

Переходи між сторінками чергуються без однакових ефектів поспіль: робоче місце, шторка, кругле розкриття або зсув сторінки. Для помічника, меню, форми та вікна звернення передбачені окремі чіткі анімації; за системного налаштування зменшеного руху анімації вимикаються. Пошук-помічник локально зіставляє опис ситуації з напрямами послуг і сторінкою вартості; клавіша `/` або `Ctrl+K` / `Cmd+K` переводить фокус до пошуку. Список підготовки до звернення та індикатор читання допомагають користуватися багатосторінковим сайтом; відмітки чекліста не зберігаються й не надсилаються.

Форма на головній сторінці перевіряє введені дані у браузері й дає змогу скопіювати підготовлений текст; вона нічого не надсилає та не зберігає.

## Запуск

Потрібен Python 3.10 або новіший. У папці `Notariys` виконайте:

```powershell
py -3 server.py
```

Відкрийте <http://127.0.0.1:8000>. Щоб переглянути сайт на телефоні в тій самій довіреній Wi-Fi мережі, встановіть пароль і запустіть сервер для локальної мережі:

```powershell
$env:NOTARY_PREVIEW_PASSWORD = "вкажіть-власний-довгий-пароль"
py -3 server.py --host 0.0.0.0 --port 8000
```

На комп’ютері виконайте `ipconfig` і знайдіть IPv4-адресу Wi-Fi адаптера (наприклад, `192.168.1.23`). Під’єднайте телефон до тієї самої Wi-Fi мережі та відкрийте `http://192.168.1.23:8000`, замінивши приклад на свою адресу. У запиті браузера введіть ім’я `parents` і заданий пароль. Якщо Windows запитає про доступ через брандмауер, дозволяйте його лише для приватних мереж. Після перегляду зупиніть сервер через `Ctrl+C`; цей спосіб не працює через мобільний інтернет або поза домашньою мережею.

Звичайний запуск без `--host 0.0.0.0` лишається доступним тільки на цьому комп’ютері. Зупинити сервер можна через `Ctrl+C`.

## API

- `GET /api/health` — перевірка доступності бекенду.
- `POST /api/inquiries` — перевірка полів `name`, `phone` і `question`.

API перевіряє вміст запиту, повертає результат і **не зберігає та не пересилає** надіслані дані. Після успішної перевірки текст звернення формується у браузері, і клієнт самостійно вирішує, чи копіювати та надсилати його.

Для закритого тимчасового перегляду встановіть змінну середовища `NOTARY_PREVIEW_PASSWORD` (щонайменше 16 символів) перед запуском `server.py`. Сервер захистить усі сторінки та API через HTTP Basic Authentication; якщо змінну не задано, локальна поведінка не зміниться. Не використовуйте цей навчальний сервер як публічний production-хостинг.

На сторінці вартості наведені лише датовані орієнтири з оприлюдненого прайсу приватного нотаріуса у Києві від 09.01.2025. Це не прайс нотаріусів Анцут і не актуальна пропозиція для Могилева-Подільського; остаточний розрахунок та окремі податки, збори й інші обов'язкові платежі потрібно уточнювати для конкретної нотаріальної дії до візиту.

GitHub Pages публікує статичну версію сайту, включно з усіма сторінками, публічно в інтернеті. Python-сервер для цієї версії не використовується; форма перевіряє дані локально у браузері. `server.py` залишається для локального запуску/API і навчальної демонстрації.
